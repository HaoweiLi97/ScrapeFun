# ScrapeFun 0.5.0

改善播放、漫画与书籍阅读和媒体库浏览，并修复旧服务端升级时的配置与数据兼容问题。

## 改进

- 改善媒体详情与关联内容的加载，减少浏览和返回媒体库时的等待。
- 统一图片裁剪操作，改善封面、背景图与头像的预览和保存体验。

## 修复

- 修复漫画阅读源选择、卷册归属及续读封面显示不一致的问题。
- 改善 EPUB 排版与触控、鼠标翻页，修复听书起始位置和阅读进度衔接问题。
- 页面加载失败后提供重试与恢复入口，减少异常时停留在空白页面的情况。
- 修复部分旧服务端升级时配置、网盘连接信息与数据目录衔接异常，改善 Linux 运行环境更新和 Android 安装空间检查。

## 更新前须知

- 请沿用当前平台、原应用和正常升级流程，保留现有连接设置与数据目录。
- 服务端更新会重启服务并短暂中断连接，请提前保留完整数据备份。
- Windows 的 GitHub 下载提供 EXE 安装包；Microsoft Store 使用 MSIX/APPX。请沿用原安装渠道，跨渠道迁移前先备份数据。
- Windows EXE 安装包未进行代码签名，系统可能显示未知发布者提示，请核对 SHA-256；商店包需完成 Microsoft Store 认证和签名后分发。
