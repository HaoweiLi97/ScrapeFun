# ScrapeFun Linux Client 0.1.3

改善播放衔接、媒体状态同步和桌面任务栏体验。

## 改进与修复

- 修复部分 Linux 桌面环境下任务栏图标与启动器不匹配、出现重复图标的问题。
- 改善连续播放与下一集切换，避免短暂显示上一集名称；统一详情页的继续播放提示。
- 及时同步媒体详情、字幕列表、阅读进度和继续观看记录，减少手动刷新。
- 扫描期间及时显示新入库内容，改善资料补全后的封面和列表刷新。
- 任务中心支持状态筛选和排序，并改善进度、失败重试与通知展示。

## 安装与兼容性

- 提供 Linux x64 的 DEB 和 AppImage，需要 glibc 2.34 或更新版本。
- 需要 X11 桌面或带 XWayland 的 Wayland 会话；暂不支持纯 Wayland 和 musl 系统。
- DEB 使用系统 libmpv，并通过系统软件包管理器更新；AppImage 自带播放库，支持应用内更新。
- 完整的扫描、匹配、任务进度与状态同步体验需连接 ScrapeFun Server 0.4.3 或更新版本。
