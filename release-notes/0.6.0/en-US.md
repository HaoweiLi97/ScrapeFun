# ScrapeFun 0.6.0

Add custom metadata to your media and arrange detail pages for each library.

## New features

- Define extra fields for movies, series, comics, and books. Scraping again preserves values you entered or cleared manually.
- Test scrapers by ID, simulate file paths, preview detail pages, and jump to errors in the scraper workbench. AI assistants can also test and save scrapers when granted the corresponding permissions.
- Improved media detail loading and added controls for extracting cover artwork from files.

## Before updating

- The upgrade changes the database schema and restarts the server. Back up the database and configuration first, and schedule the update when playback and background tasks are idle.
