# ScrapeFun Windows Client 0.5.0

改善播放、阅读和媒体库浏览，让页面恢复与后续版本更新更加清晰。

## 改进与修复

- 改善媒体详情与关联内容加载，减少浏览和返回列表时的等待。
- 统一封面、背景图与头像裁剪，改善预览和保存操作。
- 改善漫画阅读源选择、续读封面、EPUB 排版与翻页，以及听书起始位置和阅读进度衔接。
- 页面出现加载错误后提供重试与恢复入口，减少空白页面。
- 使用统一的 `0.5.0` 基础版本，正确识别后续 `0.5.0-patch.N` 正式修复更新。

## 安装与兼容性

- 适用于 Windows x64，最低系统版本为 Windows 10 2004（19041）。
- GitHub 提供 EXE 安装包，Microsoft Store 使用 APPX/MSIX。沿用原安装渠道，跨渠道迁移前先备份连接和设置。
- 请先安装本基础版，再接收同系列正式修复更新。
- EXE 安装包未进行代码签名，Windows 可能显示未知发布者提示，请核对 SHA-256；商店包需完成认证和签名后分发。
