# ScrapeFun Windows Client 0.1.3

改进媒体库扫描状态与任务中心，让入库进度和后台处理更清楚。

## 改进与修复

- 扫描期间及时显示新入库内容，改善资料补全后的封面和媒体列表刷新。
- 任务中心增加状态筛选和排序，更清楚地展示进行中、排队与需要处理的任务。
- 改进资料补全进度、失败重试、历史记录和已读通知，减少重复提示。
- 调整自动匹配设置与分集文件分配提示，减少不确定匹配被自动确认。
- 及时同步媒体详情、字幕、阅读进度和继续观看记录，减少手动刷新。
- 改善连续播放与下一集切换，避免短暂显示上一集名称；统一详情页的继续播放提示。

## 安装与兼容性

- 适用于 Windows x64，最低系统版本为 Windows 10 2004（19041）。
- 本版本采用 APPX/MSIX，通过 Microsoft Store 分发，并在验收通过后提供商店签名原包的 GitHub 下载；不再提供单独的 EXE 安装包。
- 完整的扫描、匹配和任务进度体验需连接 ScrapeFun Server 0.4.3 或更新版本。
- 旧 EXE 用户迁移前请备份连接和设置，按最终发布的迁移说明操作；跨渠道覆盖安装与数据迁移以实际验收结果为准。
