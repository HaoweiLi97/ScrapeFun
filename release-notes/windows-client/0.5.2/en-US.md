# ScrapeFun Windows Client 0.5.2

## Improvements and fixes

- Improve remote connection stability and relay fallback.
- Refine media details, resource browsing, and playback controls.
- Fix repeated danmaku position jumps during loading, pausing, and playback.

## Installation

- An x64 EXE installer is available. This GitHub EXE is unsigned; Windows may show SmartScreen or an unknown publisher prompt. Download from the official release page and check the published checksums.
