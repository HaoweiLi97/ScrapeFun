# ScrapeFun Windows Client 0.5.3

Fixes the version mismatch error shown after installing Windows Client.

## Fixes

- Fixed installation and updates reporting “The installed version does not match this release” after the application was installed.

## Installation

- Users with 0.5.2 installed can close the client and run the new installer to update.
- An x64 EXE installer is provided. This GitHub EXE is unsigned, so Windows may show a SmartScreen or unknown publisher warning. Download from the official release page and verify the checksum.
