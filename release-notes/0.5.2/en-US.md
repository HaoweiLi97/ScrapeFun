# ScrapeFun 0.5.2

This update fixes danmaku playback and Android Server updates, and improves remote connections and the experience across platforms.

## Improvements

- Improve remote connection stability and relay fallback.
- Refine media details, resource browsing, and playback controls.
- Android Server updates now stop the server automatically. Fix a stale running state that prevented updates after stopping.
- Refine Android Server navigation and settings for phones and tablets.
- Download speech models on demand to reduce initial installation size.
- Improve Linux installation checks and Fedora compatibility.

## Installation and updates

- Back up your data before updating. Server updates require a restart.
- Windows GitHub EXE installers are unsigned. Windows may show SmartScreen or an unknown publisher prompt. Download from the official release page and check the published checksums.
