# ScrapeFun 0.5.2

本次更新修复弹幕播放与 Android Server 更新问题，并改善远程连接和多平台使用体验。

## 改进与修复

- 改善远程连接与中继回退的稳定性。
- 优化媒体详情、资源浏览与播放界面的显示和操作体验。
- Android Server 更新时自动停止服务器，修复停止后仍显示运行、无法继续更新的问题。
- 调整 Android Server 导航与设置布局，改善手机和平板上的操作体验。
- 语音模型按需下载，减少首次安装占用。
- 改善 Linux 安装检查与 Fedora 兼容性。

## 安装与更新

- 更新前建议备份数据；服务更新需要重启。
- Windows GitHub EXE 为未签名安装包，Windows 可能显示 SmartScreen 或未知发布者提示。请从本项目官方发布页下载并核对校验值。
