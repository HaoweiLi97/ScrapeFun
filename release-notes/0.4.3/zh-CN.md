# ScrapeFun 0.4.3

改进媒体识别、扫描进度和任务管理，减少错配，并完善 Linux 安装与更新体验。

## 改进

- 自动匹配更重视完整标题、别名、年份和目录信息，改善同名电影、系列电影、剧集及漫画的识别，减少不确定结果被自动确认。
- 扫描时持续显示新入库内容和资料补全进度；任务中心可按状态筛选和排序，查看队列、重试失败项目并管理已读通知。
- Linux 原生安装支持自定义端口、指定版本、无人值守安装和安装前检查，并完善缺失依赖的安装提示。

## 修复

- 修复部分剧集季集编号、文件夹归属和未匹配条目再次识别不准确的问题；重新检查自动分集时保留人工确认的绑定。
- 修复大型媒体库筛选、排序及连续翻页时可能出现的内容遗漏或重复。
- 改善手动重新匹配和条目合并时的文件关联与用户记录保留；修复后台资料补全、任务通知和扫描列表刷新不及时的问题。
- 改善 Linux 更新保留端口和配置、下载校验、备份恢复及失败后的回退。
- 媒体详情、字幕列表、阅读进度和继续观看记录会随后台变化及时更新，减少手动刷新及页面间状态不一致。
- 修复连续播放切换时短暂显示上一集名称或状态的问题，改善下一集衔接、字幕导入后的剧集关联与刷新，以及有声朗读状态更新。

## 更新前须知

- Windows 服务端采用 x64 APPX/MSIX 分发，不再提供单独的 EXE 安装包。旧 EXE 安装用户迁移前请备份数据，按最终发布的迁移说明操作。
- Linux 原生包面向 glibc Linux amd64，需满足安装说明中的 Node、systemd 与媒体运行依赖要求。
- 更新需要重启服务，播放和后台任务会短暂中断；更新前请保存数据备份。
