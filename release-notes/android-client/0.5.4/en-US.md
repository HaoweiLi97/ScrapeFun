# ScrapeFun Android Client 0.5.4

This update brings the latest library display and scan status improvements to the client.

## Improvements

- Keep the home page stable during scans, reducing flicker.
- Show the current file or folder in task details and reflect queued and scanning states on library buttons.
- Update library covers and background processing status together with the server.

## Installation and compatibility

Connect to Server 0.5.4 for this release's scan behavior.
Versions from 0.5.0 use the independent client signing identity. Earlier installations using the old certificate cannot be upgraded directly; preserve the original app and back up your data first.
