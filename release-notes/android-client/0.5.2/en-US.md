# ScrapeFun Android Client 0.5.2

## Improvements and fixes

- Improve remote connection stability and relay fallback.
- Refine media details, resource browsing, and playback controls.
- Fix repeated danmaku position jumps during loading, pausing, and playback.

## Installation

- ARM64 and ARMv7 APKs support Android 7.0 or later. Choose the package for your device architecture and install over the existing app to retain data.
