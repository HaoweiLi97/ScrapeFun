# ScrapeFun 0.4.2

新增虚拟漫画库，改进离线下载、资料翻译与阅读体验，并完善账号绑定和服务器管理。

## 新功能

- 新增虚拟漫画库，可使用兼容的 HTTP 刮削来源搜索、导入、同步章节并在线阅读，保留阅读进度；此功能需要 ScrapeFun Pro。
- 新增资料翻译与文本 AI 设置，可配置翻译服务并检查连接状态。

## 改进

- 虚拟库提供来源模板与搜索导入入口，改进重复导入、来源同步和来源不可用时的提示。
- 完善离线下载设置与任务状态显示，改进占位媒体下载后与本地文件的衔接。
- 完善账号绑定、解绑与换绑，展示授权合并结果并在转移永久授权前要求确认；免费账号也可绑定和解绑，解绑后保留账号已有的 Pro 权益。
- Windows 服务端增加原生管理窗口，可查看状态与日志、启停服务、调整端口和局域网访问。

## 修复

- 修复官网解绑后服务器账号和授权状态未及时刷新的问题；解绑会结束旧的远程连接，换绑后需重新批准客户端访问。
- 修复漫画双页装订方向和翻页切换不稳定的问题，并改善远程播放分段读取与跳转的稳定性。

## 更新前须知

- 本次提供 Windows x64、Linux amd64 和 Android arm64-v8a 服务端安装包。
- 更新会重启服务并升级资料同步数据结构，播放和后台任务会短暂中断；安装前请保留数据备份。
- 虚拟漫画库需要适配的来源脚本，暂不支持需要浏览器执行的站点，也不提供整本虚拟漫画离线下载。
- 漫画图像增强保留 Waifu2x、Real-CUGAN 和 Real-ESRGAN，且不再要求 Pro；旧 ONNX、Core ML 引擎已移除，视频画质增强不受此项调整影响。
