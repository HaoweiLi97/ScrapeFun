# ScrapeFun 0.4.4

修复 Linux 原生服务的网页更新，保留更新状态、配置与数据，并完善失败后的恢复。

## 修复

- 修复 Linux 原生安装在网页检查或安装更新时误用 Docker 更新流程的问题。
- 原生 Linux 服务可从网页检查和手动安装更新；停服与重启期间保留更新状态，完成后回传结果，失败时恢复原安装与数据。
- 改善旧安装入口补齐更新工具、离线更新及配置恢复，保留现有端口、认证配置和数据位置。
- 更新与备份、恢复操作互斥，避免维护任务同时运行。

## 更新前须知

- 已有 Linux 原生安装需先重新运行一次公开的一键安装命令，或使用 `sudo scrapefun update`，安装本次服务端与更新组件后，才能使用网页安装更新。自定义实例请沿用原配置目录。
- 本次仅更新 Linux amd64 原生 Server 与配套安装、更新脚本。请核对 SHA256SUMS。
- 更新会重启服务并短暂中断播放和后台任务，请先保留完整数据备份。
