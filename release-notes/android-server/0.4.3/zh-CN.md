# ScrapeFun Server Android 0.4.3

改进媒体识别、扫描进度、任务管理与播放状态同步。

- 改善完整标题、别名、年份和目录上下文的匹配，减少不确定的自动匹配；改进季集识别并保留手动确认的绑定。
- 扫描时及时展示新入库内容和资料补全进度；任务中心支持状态筛选、排序、排队查看和失败重试，减少重复通知。
- 修复大型媒体库筛选、排序和分页时内容缺失或重复的问题，改善重新匹配和条目合并后的文件关联与用户记录保留。
- 媒体详情、字幕、阅读进度和继续观看记录会随后台变化及时更新，减少手动刷新。
- 改善连续播放与下一集衔接，避免短暂显示上一集信息，完善字幕导入后的关联和刷新。

## 安装与更新

- 这是 Android 服务端应用，与 Android 客户端分别安装；支持 Android 9 或更新版本、arm64-v8a 设备。
- APK 使用与上一版相同的发布签名，版本为 0.4.3（versionCode 4003）。更新前请停止服务并保留完整数据备份，再覆盖安装新版 APK。
- 下载后使用 SHA256SUMS 核对文件，按 Android 系统提示授权当前来源安装应用。
- 安装和首次启动需要足够的可用空间；首次准备完成后，再通过浏览器或客户端连接服务。
