[简体中文](./THIRD_PARTY_NOTICES.md) · **English**

ScrapeFun's commercial license covers only content owned by its rights holders that expressly adopts that license. Third-party components retain their copyrights and licenses. Rights those licenses grant to use, modify, obtain source code, replace, relink, and distribute components are not excluded by ScrapeFun's commercial agreement.

## Project and license references

The table helps locate projects and licenses. Whether a component is included, its version, and its build options depend on the particular distribution. This is an index of public sources, not a complete dependency inventory for every release or a completed binary license audit.

| Component or resource | Purpose | Official project and license reference |
| --- | --- | --- |
| Node.js | Server runtime | [Node.js LICENSE](https://github.com/nodejs/node/blob/main/LICENSE) |
| Electron | Desktop client host | [Electron LICENSE](https://github.com/electron/electron/blob/main/LICENSE) |
| FFmpeg / FFprobe | Media probing, subtitles, and media processing | [FFmpeg Legal](https://ffmpeg.org/legal.html) |
| mpv / libmpv | Native media playback | [mpv Copyright](https://github.com/mpv-player/mpv/blob/master/Copyright) |
| mpv-android | Source of Android native player integration | [mpv-android](https://github.com/mpv-android/mpv-android) |
| Sparkle | macOS Server updates | [Sparkle LICENSE](https://github.com/sparkle-project/Sparkle/blob/2.x/LICENSE) |
| Velopack | Windows Server installation and updates | [Velopack LICENSE](https://github.com/velopack/velopack/blob/develop/LICENSE) |
| thumbfast | Thumbnails in some players | [thumbfast](https://github.com/po5/thumbfast) |

The applicable licenses for FFmpeg and mpv / libmpv depend on actual build options and dependencies. A component name alone is insufficient to classify a distribution as LGPL or GPL. Models, fonts, icons, and other dependencies also require verification against their sources and supplied notices.

## Information supplied with distributions

Distributors should include copyright notices and license texts as required by each component's license. Where corresponding source code, build information, or other materials are required, supply them for the actual version and license. This page does not replace those obligations if a distribution omits required information.

For licensing or source-code access information about a particular distribution, contact `scrapefun@outlook.com` and include the platform, version, and complete asset filename. Do not include activation codes, account passwords, or private media in public reports.
