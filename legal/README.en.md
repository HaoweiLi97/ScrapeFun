## Scope

The new agreement applies to new content expressly adopting it and to later official versions expressly referencing it in their release information or distribution packages. It does not retroactively change licenses already in effect for earlier versions. Updating GitHub documentation does not automatically relicense existing releases, Docker images, or installers.

Check the license, copyright notices, and release information for each platform repository and distribution. Third-party components always retain their own licenses.

## Statements in later distributions

A later distribution adopting this agreement should include the license statement and full agreement, and identify the agreement version and links in its release notes. Where installation confirmation is involved, users should have an opportunity to read the terms before installing. Third-party notices, license texts, and required source code or access instructions must still accompany distributions as required by the actual components and build configurations.
