## 从哪里开始

本指南按当前标记为 0.5.1 的开发版本核对，已发布版本的名称和可用选项可能不同。Server 管理员负责实例级设置；个人外观与阅读偏好按当前客户端和页面提供的选项调整。先完成[安装与部署](https://scrapefun.com/?lang=zh#/docs/linux)，再连接存储、创建媒体库和运行首次扫描。

设置中的连接密码、API Key、私有地址与完整备份均应保密。对外分享时只提供必要字段的脱敏片段，不上传整份配置。模型与接口配置见[AI 接入](ai-settings.md)，程序调用见[API 参考](api.md)。

<a id="libraries"></a>

## 存储与媒体库

| 入口或字段 | 用途与填写要求 | 保存后验证 |
| --- | --- | --- |
| 存储与下载 | 添加页面支持的存储来源，填写来源地址和访问凭据 | 先浏览少量真实文件，确认 Server 可访问 |
| 媒体库名称与类型 | 使用易辨认的名称，选择电影、剧集、漫画或书籍等正确类型 | 检查库类型与实际内容相符 |
| 媒体目录 | 选择 Server 能看到的目录；Docker 使用容器内已挂载路径 | 确认目录有文件且具备所需读权限 |
| 刮削器 | 选择支持该库类型和所需能力的活动来源 | 对一条作品检查搜索与详情 |
| 元数据与图片语言 | 按优先级选择来源支持的语言 | 检查标题、简介和图片是否符合预期 |

先在小目录完成扫描再扩大范围。虚拟媒体库依赖来源的发现、导入或漫画章节能力，不能用文件扫描替代；仅有漫画元数据不代表能够在线阅读。不要为修复单次失败直接删除整个库，先检查任务错误和存储连接。

<a id="scraping"></a>

## 刮削与匹配

“刮削与匹配”管理识别、文件名清洗和元数据翻译。去噪词用于去除资源名称中的无关文字，保留作品名、年份、季集编号等有效信息。先用[清洗测试](scraper-api.md#cleaning)检查结果，再绑定到来源。

发生误配时，先核对库类型、来源和文件名，然后检查候选标题、年份与 ID。匹配调优中的阈值、领先差值与搜索变体数量会影响候选筛选和请求量，优先保持默认，每次只修改一项并用同一批样本对比。不要用降低阈值代替修复错误的来源数据。

自动翻译、翻译范围和提示词在同一区域配置；先绑定已启用的[文本 AI 连接](ai-settings.md#translation)。自定义刮削器的能力、编写和保存流程见[开发参考](scrapers.md)。

<a id="reading"></a>

## 阅读与默认打开方式

| 设置 | 适用范围 |
| --- | --- |
| 外观与首页 | 调整页面提供的外观和首页显示选项；保存后检查当前客户端实际显示 |
| 默认打开方式 | 为页面支持的资源类型选择已安装且能处理该资源的应用 |
| 漫画阅读设置 | 页面加载与图像处理；具体阅读方向、触摸区与背景按阅读器内选项调整 |
| 书籍阅读设置 | 默认字体排版、布局、主题与 PDF 显示；打开一本书检查效果 |
| AI 配置 | 管理听书的语音连接与图像增强模型；各自独立于文本模型连接 |

设置显示正常不代表所有资源格式都受支持，需用实际书籍或漫画验证。先记录原值，再调整影响阅读的选项；涉及远程语音时先测试短文本，确认声音和费用后再长时间使用。

<a id="tasks-access"></a>

## 自动化、任务与访问

“自动化”用于管理实例当前支持的计划任务。先手动运行一次确认目录、来源和权限，再设置频率；避免对同一库安排重叠扫描。任务开始后从任务列表查看状态和错误，按页面提供的能力暂停、取消或重试。

“用户与设备”管理用户、媒体库访问和已连接设备。普通用户只授予需要的库；更改权限后用对应用户验证可见内容。撤销或移除设备可能中断正在使用的会话，操作前确认目标设备。不要在公开问题中附带设备凭据或完整用户列表。

使用 AI 自动化时，先说明允许访问的库与允许的写操作。查询、启动扫描、更新元数据和删除资料具有不同影响；已有权限不等于用户已要求执行全部动作。任务接口见[扫描与跟踪](api.md#tasks)。

<a id="maintenance"></a>

## 缓存、连接与维护

“缓存管理”用于查看实例显示的缓存用量、容量和清理选项。确认正在处理的是缓存还是原始资料，并按页面操作提示执行；清理后相关内容可能需要重新生成或下载。不要把缓存目录当作完整备份。

“服务与连接”中的网络代理只在确有网络访问需要时配置。使用真实代理地址及自己的凭据，先测试连接，再验证所需来源；更改代理不保证所有客户端和资源都自动使用它。不要把代理密码嵌入公开 URL 或日志。

“维护与更新”集中备份、恢复、版本与重启操作。更新或恢复前先备份；重启会中断连接和后台工作。恢复与重置按页面明确范围操作，不能用于普通连接故障的首轮排查。具体步骤见[数据、备份与恢复](https://scrapefun.com/?lang=zh#/docs/data)及[更新与维护](https://scrapefun.com/?lang=zh#/docs/updates)。

“高级设置”用于实例提供的硬件和处理参数调优。没有可复现问题时保留默认；更改前记录原值，修改后核对耗时、资源占用和实际结果。公开反馈只提供必要的脱敏错误信息。
